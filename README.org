* Description

This layer integrates [[https://github.com/xenodium/agent-shell][agent-shell]] with Spacemacs.

** Features

- Evil-mode integration for all agent-shell buffer types
- Major-mode leader bindings (~,~ / ~SPC m~) for ~agent-shell-mode~, ~agent-shell-viewport-view-mode~, and ~agent-shell-viewport-edit-mode~
- Per-mode transient states (~C-c .~) for navigation and session management
- A global prefix map (default ~C-c s~) for send/jump/create operations from any buffer
- ~agent-shell/set-project~ to re-point a running shell at a different project directory without restarting the session

** Evil state assignments

| Buffer type                         | Evil state | Rationale                                                      |
|-------------------------------------+------------+----------------------------------------------------------------|
| ~agent-shell-mode~                  | normal     | Full editing; ~RET~ sends in normal state, newlines in insert  |
| ~agent-shell-viewport-view-mode~    | motion     | Read-only viewer; vim navigation, no insert                    |
| ~agent-shell-viewport-edit-mode~    | insert     | Compose buffer; stays in insert for typing                     |
| ~*agent-shell-diff*~                | emacs      | Diff buffers have their own complete key scheme                |

* Install

** Requirements

- [[https://github.com/xenodium/acp.el][acp.el]]
- [[https://github.com/xenodium/shell-maker][shell-maker]]
- [[https://github.com/xenodium/agent-shell][agent-shell]]

** Setup

1. Copy or symlink this layer directory into your Spacemacs private layers path
   (typically =~/.emacs.d/private/=).

2. Ensure ~acp~ and ~shell-maker~ are declared (e.g. in ~dotspacemacs-additional-packages~):

   #+begin_src emacs-lisp
   dotspacemacs-additional-packages '(shell-maker
                                      (acp :location (recipe
                                                      :fetcher github
                                                      :repo "xenodium/acp.el")))
   #+end_src

3. Add the layer to ~dotspacemacs-configuration-layers~:

   #+begin_src emacs-lisp
   (agent-shell :variables
                agent-shell-layer-global-key "C-c s")
   #+end_src

   To use a local source checkout instead of the GitHub recipe (e.g. when working
   on a fork):

   #+begin_src emacs-lisp
   (agent-shell :variables
                agent-shell-layer-source-path "~/dev/agent-shell"
                agent-shell-layer-global-key  "C-c s")
   #+end_src

** Authentication

Authentication is personal and environment-specific. Supply it via
~agent-shell-layer-configure-fn~, which is called at the end of the layer's
~:config~ phase once all agent-shell functions are loaded:

#+begin_src emacs-lisp
(agent-shell :variables
             agent-shell-layer-global-key "C-c s"
             agent-shell-layer-configure-fn
             (lambda ()
               (setq agent-shell-anthropic-authentication
                     (agent-shell-anthropic-make-authentication :login t)
                     agent-shell-preferred-agent-config
                     (agent-shell-anthropic-make-claude-code-config)
                     agent-shell-session-strategy 'prompt)))
#+end_src

* Layer variables

| Variable                          | Default      | Description                                                         |
|-----------------------------------+--------------+---------------------------------------------------------------------|
| ~agent-shell-layer-source-path~   | ~nil~        | Path to a local agent-shell checkout; takes precedence if non-nil  |
| ~agent-shell-layer-global-key~    | ~"C-c s"~    | Global prefix key for the agent-shell command map                   |
| ~agent-shell-layer-configure-fn~  | ~nil~        | Called at end of config phase; set authentication and personal vars |

* Commands

** ~agent-shell/set-project~

Re-points a running agent-shell buffer at a different project directory without
restarting the session.

- Called from an agent-shell or viewport buffer: targets that buffer's shell
- Called from any other buffer: prompts to select a shell buffer via completing-read

Prompts for a directory, defaulting to the current project root. Overrides
~agent-shell-cwd-function~ buffer-locally, bypassing projectile and project.el for
that shell only. The override persists until the buffer is killed or the command
is called again.
